# Blueberry Productivity

Automatically creates repeatable productivity technologies for intermediate products, just like the infinite research added by Space Age.

## Features

- Technologies are generated from the recipes, so content added by other mods is supported automatically.
- Each technology grants **+10% recipe productivity per level**, has **30 levels** (up to +300% productivity)
- Alternate recipes shares one clear productivity technology.

## Compatibility

- Factorio **2.1**
- Space Age
- Space Age Galore
- Existing progress is migrated from the replaced Space Age technologies
- Existing progress from **Expanded Productivity Research** is migrated when possible

Mod authors can customize generated technologies through the [mod integration API](MODDING.md).

## Configuration

The defaults are ready to play, but startup settings let you:

- Include product who do not normally allow productivity
- Merge several products into one technology
- Ignore individual recipes or entire product groups
- Define custom research-cost presets
- Assign presets by recipe category, product type, or product name
- Keep or remove Space Age's overlapping productivity technologies
